# Asian Paints – Financial Modelling & Valuation

## Objective

To analyse Asian Paints' historical financial performance, forecast key financial metrics, estimate the cost of capital, and evaluate the company's value using multiple valuation approaches.

## Analysis Performed

- 10-year historical financial statement and ratio analysis
- Revenue, profitability, working capital and cash-flow analysis
- Financial forecasting and back-testing
- Beta estimation using regression and peer comparison
- WACC estimation using a bottom-up approach
- ROIC, reinvestment rate and intrinsic growth analysis
- Common-size financial statement analysis
- DCF valuation using FCFF
- Comparable-company valuation using EV/Revenue, EV/EBITDA and P/E
- Football-field valuation analysis
- Value at Risk (VaR) using historical simulation
- Monte Carlo simulation

## Key Findings

- FY26 revenue recovered by approximately 4.95% after a decline in FY25, while EBITDA grew faster than revenue.
- Gross margin and EBITDA margin improved, supported by lower material-cost intensity and stronger operating efficiency.
- Cash Conversion Cycle improved from approximately 75 days to 53 days, primarily due to lower inventory days.
- ROCE declined from approximately 35% to 32.7%, highlighting a key concern around capital productivity despite continued investment.
- The bottom-up WACC estimate was 12.42%.
- Intrinsic growth estimates showed a declining trend, driven primarily by a reduction in the reinvestment rate.
- Base-case DCF implied a value of approximately ₹614 per share, while comparable-company valuation produced a range of approximately ₹1,375–₹1,888 per share.
- Both valuation approaches were below the modelled market price, highlighting the sensitivity of valuation to assumptions and methodology.

## Valuation & Risk Analysis

The project compares intrinsic and market-based valuation approaches and evaluates sensitivity to key assumptions. Risk analysis was supplemented using historical VaR and Monte Carlo simulation.
